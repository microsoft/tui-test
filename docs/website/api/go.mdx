`github.com/microsoft/tui-test/bindings/go` (`package tuitest`) runs the `tui-test` Rust engine in-process via PureGo without cgo, Rust, Zig, or the CLI binary.

## Install

Use Go 1.26 or newer and pin a published module release so Go fetches the tagged tree containing prebuilt native libraries:

```sh
go get github.com/microsoft/tui-test/bindings/go@v0.1.1
```

| OS | `GOARCH` | Runtime requirements |
| --- | --- | --- |
| Linux | `amd64`, `arm64` | glibc 2.28+ or musl 1.2+ |
| macOS | `amd64`, `arm64` | macOS system libraries |
| Windows | `amd64` | Windows system libraries (includes bundled ConPTY) |

On first use, the module verifies and extracts the matching platform library into the user cache (`tui-test/native/<sha256>/`) and reuses it across subsequent runs without network requests.

### Cross-compilation and custom native libraries

Linux builds select the GNU or musl engine automatically at runtime. Cross-compile for glibc Linux with `CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build .`. When cross-compiling a musl binary from a non-musl host, also set the dynamic linker (`-ldflags '-I /lib/ld-musl-x86_64.so.1'` or `/lib/ld-musl-aarch64.so.1`).

For read-only filesystems or local source checkouts (which do not embed release archives), set `TUI_TEST_NATIVE_LIBRARY` to the absolute path of `libtui_test_ffi.so`, `libtui_test_ffi.dylib`, or `tui_test_ffi.dll`. An invalid override fails immediately rather than falling back. See [building from source](/docs/contributing/#build-from-source).

## Quick start

```go
package main

import (
    "fmt"
    "log"

    "github.com/microsoft/tui-test/bindings/go"
)

func main() {
    terminal, err := tuitest.Ephemeral("example", tuitest.ClientOptions{})
    if err != nil {
        log.Fatal(err)
    }
    defer terminal.CloseQuiet()

    if _, err := terminal.Open(tuitest.OpenOptions{}); err != nil {
        log.Print(err)
        return
    }
    if err := terminal.Submit(tuitest.Ptr("echo hello")); err != nil {
        log.Print(err)
        return
    }
    if err := terminal.WaitCommand(tuitest.WaitOptions{}); err != nil {
        log.Print(err)
        return
    }
    output, err := terminal.GetOutput()
    if err != nil {
        log.Print(err)
        return
    }
    if output != nil {
        fmt.Print(*output)
    }
}
```

Verify a published install without a shell by running `go run github.com/microsoft/tui-test/bindings/go/examples/smoke`.

## Sessions and options

`tuitest.New(session, ClientOptions{})` binds a named session (`TUI_TEST_SESSION` or `"default"` when empty), while `tuitest.Ephemeral(prefix, ClientOptions{})` generates a unique name. Pointer fields (created with `tuitest.Ptr(v)`) distinguish omitted options from explicit zero or `false` values, and durations use `*time.Duration`.

`ClientOptions` configures `Backend` (`Alacritty`, `Ghostty`, `Rio`, `XtermJS`), `Profile`, `Style` (`*RenderStyle`), `Timeouts`, `ScreenHistoryLimit`, `Recording` (`RecordingDisabled`, `RecordingOnFailure`, `RecordingAlways`), `Artifacts` (`ArtifactNone`, `ArtifactText`, `ArtifactHTML`, `ArtifactAll`), `Trace` (`TraceOff`, `TraceOnFailure`, `TraceOn`), and `Context` (`*ExecutionContext`). `SpawnOptions` (embedded by `OpenOptions` alongside `Shell`) accepts per-launch `Backend`, `Cols`, `Rows`, `Cwd`, `Env`, `WaitReady`, `Restart`, `Retries`, `Profile`, `Style`, `Timeouts`, `Recording`, `ScreenHistoryLimit`, and `Context`.

## `Locator`

```go
save := terminal.GetByText("Save", tuitest.TextSelectorOptions{
    Scope: &tuitest.TextScope{
        After:  &tuitest.TextAnchor{Text: "Network"},
        Before: &tuitest.TextAnchor{Text: "Advanced"},
    },
}).WithStyle(tuitest.TextStyle{Bold: tuitest.Ptr(true)}).
    RelativeTo(terminal.GetByText("Settings", tuitest.TextSelectorOptions{}), tuitest.After)

if err := save.Unique().Click(tuitest.LocatorClickOptions{}); err != nil {
    t.Fatal(err)
}
```

- Create or chain with `GetByText`, `GetByStyle`, `GetByLink`, `WithStyle`, and `RelativeTo(parent, direction)` (`Within`, `After`, `Before`).
- Compose with `And(other)`, `Or(other)`, and `Filter(LocatorFilterOptions{Has, HasNot})`.
- Select occurrences with `Any`, `Unique`, `First`, `Last`, or `Nth(index)`.
- Inspect or act with `Locations`, `Location`, `Count`, `All`, `Wait`, `Expect`, `Click`, `Highlight`, and `HighlightMatches`.

## Errors and `tuitesttest`

Unwrap `*tuitest.Error` with `errors.As` to read `Kind` (`AssertionError`, `UsageError`, `NoSessionError`, `InternalError`), `Operation`, `Details` (`*FailureDetails`), and `Artifact` (`*FailureArtifactRef`).

In `testing` suites, import `github.com/microsoft/tui-test/bindings/go/tuitesttest` and call `tuitesttest.New(t, tuitesttest.Options{})`. It allocates a unique session name, registers `t.Cleanup` before launching the terminal, forwards `t.Failed()` so `TraceOnFailure` retains failed test traces automatically, and stays safe across `t.Parallel()` tests.
