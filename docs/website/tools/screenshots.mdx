## Text captures

```sh
tui-test screenshot
```

Without an output path, `screenshot` returns terminal text.
Use `text` when you only need a text read.

## SVG screenshots

```sh
tui-test screenshot -o result.svg
```

SVG captures preserve terminal styling and name the configured fonts.
They render with fonts installed on the machine that opens the file.

## PNG screenshots

```sh
tui-test screenshot result.png
```

The extension selects PNG or SVG.
Rust callers need the raster feature and suitable fonts for PNG output.
The [native language packages](/docs/install/#libraries) include their engine.

## Visible viewport and scrollback

Captures use the selected native history viewport.
Add `--full` to include retained scrollback.
Cursor state keeps application coordinates, but captures project the cursor
into the view and hide it outside the viewport.

## Highlight locator matches

```sh
tui-test highlight text "Ready"
tui-test screenshot -o highlighted.svg
```

Highlights also appear in the [live monitor](/docs/tools/monitor/).
Use text selection or style constraints to mark the same match your test uses.

## Zoom and fonts

`--zoom N` changes the capture scale.
Configure font families, sizes, and additional font files in
`[recording.style]`. Use monospace fonts; glyphs are fitted into fixed-width
terminal cells.

Raster output uses installed or loaded fonts. Unavailable fonts fall back.
SVG names a font family but does not embed custom font files.

## Canvas backgrounds and transparency

```sh
tui-test screenshot -o result.png --background '#101014'
tui-test screenshot -o result.svg --transparent
```

Background and transparency are mutually exclusive and require an output path.
They control the outer canvas, separately from terminal-cell and window colors.

## Window styling and profile overrides

`[recording.style]` controls the title bar, canvas and content padding, border,
shadow, and fonts. Profiles inherit omitted keys.
Failure SVGs and the SVGs embedded in HTML reports use the session style.

See the [configuration guide](/docs/guides/configuration/#configure-capture-styles)
for a dark theme and the
[style reference](/docs/reference/configuration/#recording-style) for defaults.
