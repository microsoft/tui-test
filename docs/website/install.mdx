`tui-test` runs on Windows, Linux, and macOS. Install the CLI for terminal
automation, or a library to use the engine from your code.

## CLI

The installer downloads the latest stable release for your operating system and architecture.

<Tabs>
  <TabItem label="macOS and Linux">
    ```sh
    curl -fsSL https://tui-test.dev/install.sh | sh
    ```
  </TabItem>
  <TabItem label="Windows">
    ```powershell
    irm https://tui-test.dev/install.ps1 | iex
    ```
  </TabItem>
</Tabs>

### Homebrew

```sh
brew tap microsoft/tui-test https://github.com/microsoft/tui-test
brew install tui-test
```

You can also download platform archives from [GitHub Releases](https://github.com/microsoft/tui-test/releases).

### Verify the installation

```sh
tui-test --version
```

If your shell cannot find `tui-test`, restart the terminal or check that the installation directory is on your `PATH`.

## Libraries

Library sessions run in your process and do not require the CLI.

<Tabs syncKey="example-language">
  <TabItem label="Python">
    Requires Python 3.8 or newer.

    ```sh
    pip install tui-test
    ```

    The wheel includes the native library.
    [Python API](/docs/api/python/)

  </TabItem>
  <TabItem label="JavaScript">
    Requires Node.js 20 or newer.

    ```sh
    npm install @microsoft/tui-test
    ```

    The package is ESM only. Keep optional dependencies enabled; they include
    native platform binaries. Bun and Deno are best effort; Deno 2 needs local
    `node_modules` and `--allow-ffi`.
    [JavaScript and TypeScript API](/docs/api/javascript/)

  </TabItem>
  <TabItem label="Rust">
    Requires Rust 1.90 or newer.

    ```sh
    cargo add tui-test-rs
    ```

    Add `recording-raster` for APNG, GIF, and MP4 output. It uses installed
    fonts; `recording-font-jetbrains-mono*` features bundle a font.
    [Rust guide](/docs/api/rust/) and
    [full API reference](https://docs.rs/tui-test-rs/latest/tui_test/)
  </TabItem>
  <TabItem label="Go">
    Requires Go 1.26 or newer. Published modules include the native engine.

    ```sh
    go get github.com/microsoft/tui-test/bindings/go@latest
    ```

    Published modules support Linux and macOS on `amd64` and `arm64`, and
    Windows on `amd64`. Linux requires glibc 2.28+ or musl 1.2+.
    [Go API and runtime requirements](/docs/api/go/)

  </TabItem>
</Tabs>

To use an existing native library, set `TUI_TEST_NATIVE_LIBRARY` to its absolute
path. It must match your language package's release and platform.
