## Create a baseline

```sh
tui-test expect text "Ready"
tui-test expect snapshot main-screen
```

If the baseline does not exist, the assertion writes it. Review and commit the
new file before relying on it in CI.

## Compare terminal output

Run the same assertion again to compare the current terminal with the baseline.
Set the grid, backend, and relevant environment consistently. Wait for a known
application state before capturing the snapshot.

## Include styles and window titles

```sh
tui-test expect snapshot main-screen --include-style --include-title
```

Python uses `include_style` and `include_title`; JavaScript uses `includeStyle`
and `includeTitle`. Go uses `SnapshotOptions`.
Style snapshots include cell attributes, colors, underline styles, and
hyperlink targets. Title inclusion records the full title.

## Normalize text with test helpers

For comparisons in your own runner, JavaScript's `terminalSnapshot`, Python's
`terminal_snapshot`, and Go's `tuitesttest.TerminalSnapshot` normalize text by
removing trailing whitespace and blank lines.
These helpers are separate from the native `.snap` baseline format.

## Snapshot names and directories

Snapshots are stored as `__snapshots__/NAME.snap` under the snapshot base
directory. The CLI uses the client's working directory, not the daemon's.
Spaces and filename-unsafe characters in names are replaced with hyphens.
Go's snapshot options can select a working directory.

## Review a mismatch

A mismatch returns an assertion failure with expected and actual content.
Use [failure diagnostics](/docs/tools/failure-diagnostics/) to inspect the
screen and operation that produced it. A changed baseline should reflect an
intentional application change.

## Update a baseline

```sh
tui-test expect snapshot main-screen -u --include-style --include-title
```

Python and JavaScript accept `update=True` and `update: true`, respectively.
Go returns `SnapshotPassed`, `SnapshotWritten`, or `SnapshotUpdated`.
Enable updates only when reviewing a new baseline, not in ordinary CI runs.
