`tui-test` records live terminal sessions into animated raster media (`.gif`, `.apng`/`.png`, `.mp4`) or timestamped asciinema streams (`.cast`). For scripted demos written in a declarative VHS-like syntax, see [tape files](/docs/capture/tapes/).

## Formats and requirements

| Extension | Format | Requirements |
| --- | --- | --- |
| `.gif` | Animated GIF | Built in on CLI, JS, Python, and Go; `recording-raster` + fonts in Rust. |
| `.png`, `.apng` | Animated PNG | Built in on CLI, JS, Python, and Go; `recording-raster` + fonts in Rust. |
| `.mp4` | H.264 MP4 video | Same raster support plus `ffmpeg` on `PATH` (no transparent background). |
| `.cast` | Asciinema v2 stream | No font or raster dependencies; replay in any asciinema player. |

The output path extension chooses the format unless overridden by `format` (`--format`).

## Start, pause, resume, and stop

Raster recordings sample the live terminal at `fps` (default `30`) and preserve real elapsed time until `stopRecording` finishes writing the file. Use `pauseRecording` and `resumeRecording` to skip slow setup steps in `.gif`, `.apng`, or `.mp4` captures while the child process keeps running; asciinema `.cast` streams reject pause and resume.

## Timing, cursor blink, and automatic casts

`idleTimeLimit` (`--idle-time-limit SECONDS`) caps unchanged intervals before `speed` (`--speed`) scales frame durations. By default there is no idle cap and no extra hold after `stop`.

Cursor animation requires both `style.cursor.blink = true` (default) and an application cursor shape that requests blinking. Each visible or hidden phase lasts `blinkIntervalMs` (default `500` ms) before speed scaling.

Automatic asciinema recordings are controlled separately from explicit `startRecording` calls via `[trace]` or `recording: { mode: "disabled" | "on-failure" | "always", directory }`. Retrieve an active or retained automatic cast with `tui-test get-recording`, `getRecording(session)`, `get_recording(session)`, `Recording(session)`, or `session.recording()`. Automatic casts remain continuous even while a raster recording is paused. Recorded files can contain terminal text, environment output, and window titles; review captures before publishing or attaching them to public issues.
